# Central de Pesquisas

Repositório pessoal para guardar, organizar e consultar pesquisas.

## Como usar

Mande a sua pesquisa para o Claude numa sessão deste repositório. Pode ser:

- um **tema** para pesquisar ("pesquise sobre X");
- um **texto, link ou anotação** seu para organizar e guardar;
- um **arquivo** (PDF, planilha, imagem) para resumir.

O Claude salva cada pesquisa como um arquivo Markdown em `pesquisas/`, atualiza o
índice abaixo e faz commit. Assim tudo fica versionado e fácil de achar depois.

## Estrutura

```
pesquisas/
  INDICE.md                 # lista de todas as pesquisas
  _modelos/pesquisa.md      # modelo usado em cada nova pesquisa
  AAAA-MM-DD-titulo.md      # uma pesquisa por arquivo
anexos/                     # arquivos enviados (PDFs, imagens, planilhas)
_legado/                    # conteúdo antigo do repositório (exercício ADO JS)
```
